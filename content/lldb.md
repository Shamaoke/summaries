# Команды #
{: id="Команды" }

`target create TARGET [--core DUMP]` / `file ...`

: * Создать цель отладки, загрузив указанный исполняемый файл (`TARGET`)

  * Загрузить отладочные символы из отдельного файла (`DUMP`)

`target list`

: Вывести упорядоченный список всех загруженных в текущей сессии целей отладки

`target select INDEX`

: Переключить контекст отладчика на другую цель (`INDEX`) из списка ранее
  загруженных целей

`target delete {INDEX|--all}`

: Удалить заданную цель (`INDEX`) или все цели (`--all`) из текущей отладочной
  сессии, освобождая связанную с ними память и отладочные символы

`breakpoint set -f|--file FILE -l|--line LINE` / `b ...`

: Установить точку останова в указанном файле (`FILE`) на заданной строке (`LINE`)

`breakpoint set -n|--name FUNCTION`

: Установить точку останова на указанной функции (`FUNCTION`)

`breakpoint set -r|--func-regex FUNCTION`

`breakpoint set -M|--method METHOD`

`breakpoint set -F|--fullname FUNCTION`

`breakpoint list` / `br ...`

: Вывести список точек останова, созданных в текцщей цели отлдаки

`breakpoint delete [--force]` / `br ...`

: Удалить все точки останова из текущей цели отладки (без подтверждения `--force`)

`breakpoint delete ID` / `br ...`

: Удалить указанную точку останова (`ID`)

`platform settings -w|--working-dir DIRECTORY`

: Установить текущий рабочий каталог (`DIRECTORY`)

`settings set target.env-vars NAME1=VALUE1 NAME2=VALUE2 ...`

: Задать переменные окружения (`NAME1=VALUE1`, `NAME2=VALUE2`) для отлаживаемой
  программы до её старта

`settings show target.env-vars`

: Вывести список установленных переменных окружения

`settings clear target.env-vars`

: Удалить все установленные переменные окружения

`patform shell SHELL_COMMAND` / `shell ...`

: Выполнить команду системной командной оболочки (`SHELL_COMMAND`) внутри
  изолированного подпроцесса и вывести результат в консоль

`image lookup -r|--regex -n|--name NAME`

: Выполнить поиск символов в загруженных исполняемых файлах и динамических
  библиотеках (то, что называется `image`) по регулярному выражению

`type lookup NAME`

: Вывести внутреннюю структуру типа (класса, структуры или перечисления),
  заданного именем (`NAME`) , на основе отладочной информации приложения

`expression [-T|--show-types] -- EXPRESSION` / `expr ...`

: * Вычислить заданное выражение (`EXPRESSION`) в текущем контексте

    Выражение будет вычислено путем запуска реального кода внутри процесса
    отлаживаемого приложения. Если вычисляемое выражение изменит состояние
    программы, это изменение останется в силе для текущей сессии отладки.

  * Указать типы данных для всех полученных значений

    Разделитель (`--`) обязателен в случае использования опций командной строки.

`frame variable --show-types` / `fr v -T`

: * Вывести список всех локальных переменных и аргументов в текущем выбранном
    стековом фрейме

  * Указать типы данных для переменных и аргументов (`--show-types`)

`process launch` / `run` / `r`

: Запустить исполняемый файл текущей цели отладки

`process launch --stop-at-user-entry`

: * Запустить исполняемый файл текущей цели отладки

  * Остановиться на точке входа в программу (функция `main` для C++)

`process kill` / `kill`

: Принудительно завершить текущий запущенный процесс отлаживаемого приложения

`platform list`

: Перечислить все доступные платформы
