# Глоссарий #
{: id="Глоссарий"}

**ad hoc**

по требованию/необходимости

**arrange**

выстраивать

_to arrange in a row — выстраивать в ряд_

**boilerplate**

: оснастка

**commit**

зафиксированная (закрепленная) правка

**to commit**

фиксировать изменения (правки)

compiler

: _компилятор_

  Программа или техническое средство, выполняющие компиляцию

  Комплексная программа, осуществляющая цепочку преобразований исходного кода в набор машинных инструкций

compilation

: _компиляция_

  Трансляция программы с языка высокого уровня в форму на машинном языке

constant expression

: константное выражение

control flow

: _поток управления (вычислениями, вычислительной машиной)_

  _поток команд (управляющих вычислениями)_

  Последовательность управляющих команд

**dangling**

: висячий, зависший, повисший, оборванный, несвязанный

: _dangling Docker volume_ — виртуальный накопитель Докера, не связанный ни с одним существующим контейнером

: _dangling pointer_ — указатель, указывающий на несуществующий объект; повисший указатель

data

: данные

declaration

: _объявление_

definition

: _определение_

**denote**

обозначать

**exception handling**

перехват исключений

**extensionality**

экстензиональность; состав (множества)

facitlity

: средство

**feature**

составная часть (важная, заметная, значимая); быть в составе/являться составной частью чего-либо (напр. программного продукта)

**generic**

: полиморфный тип/класс; параметризованный тип/класс; обобщенный тип/класс

  _generic data type — полиморфный тип данных_

implicit

: неявный

  _implicit constant — неявная константа_

inline

: встраиваемый

  _inline function — встраиваемая функция_

**interactive environment, REPL**

интерактивное окружение

**layout**

компоновка

lexical unit, lexical token

: _лексема_

  Языковая конструкция, представляющая элементарную синтаксическую единицу

literal

: _литерал_

  Лексема, непосредственно представляющая некоторое значение

locus of control

: _локус контроля_

  Месторасположение управляющих команд; подпрограмма, сопрограмма или тред

log

: журнал, протокол

logging

: журналирование, протоколирование, регистрация событий

log message

: регистрационная запись

**long-term**

перспективный

**pattern**

закономерность

**pragmatics**

: практика применения

**random**

: произвольный

  _at random times — в произвольные моменты времени_

**range**

: участок

  _range within the program — участок программы_

**reverse**

: оборотный

  _reverse proxy-server — оборотный прокси-сервер_

**runtime**

: рабочий модуль

**sandbox**

изолированное окружение

**sanity check**

: санитарная проверка; проверка исправности

**sequence**

ряд

**specifier**

: определитель

statement

: предложение, инструкция, оператор, выражение

**tool**

инструментальная программа

translation

: _трансляция_

  Преобразование программы, представленной на одном языке программирования, в
  программу на другом языке и в определенном смысле равносильную первой

**type checker**

контролёр типов

value, data value

: величина, экземпляр данных; значение
