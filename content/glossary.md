# Глоссарий #
{: id="Глоссарий"}

ad hoc

: _по требованию/необходимости_

arrange

: _выстраивать_

  _to arrange in a row — выстраивать в ряд_

assignment

: _присваивание_

boilerplate

: _оснастка_

commit

: _зафиксированная (закрепленная) правка_

commit, to

: _фиксировать изменения (правки)_

compiler

: _компилятор_

  Программа или техническое средство, выполняющие компиляцию

  Комплексная программа, осуществляющая цепочку преобразований исходного кода в набор машинных инструкций

compilation

: _компиляция_

  Трансляция программы с языка высокого уровня в форму на машинном языке

constant expression

: _константное выражение_

control flow

: _поток управления_ (вычислениями, вычислительной машиной)

  _поток команд_ (управляющих вычислениями)

  Последовательность управляющих команд

dangling

: _висячий_, _зависший_, _повисший_, _оборванный_; _несвязанный_

  _dangling Docker volume_ — виртуальный накопитель Докера, не связанный ни с одним существующим контейнером

  _dangling pointer_ — указатель, указывающий на несуществующий объект; повисший указатель

data

: _данные_

declaration

: _объявление_

definition

: _определение_

denote

: _обозначать_

exception handling

: _перехват исключений_

extensionality

: _экстензиональность_; _состав_ (множества)

facitlity

: _средство_

feature

: _составная часть_ (важная, заметная, значимая)


feature, to

: _быть в составе/являться составной частью чего-либо_ (напр. программного продукта)

generic

: _полиморфный тип/класс_; _параметризованный тип/класс_; _обобщенный тип/класс_

implicit

: _неявный_

  _implicit constant — неявная константа_

inline

: _встраиваемый_

  _inline function — встраиваемая функция_

interactive environment

: _интерактивное окружение_

layout

: _компоновка_

lexical unit, lexical token

: _лексема_

  Языковая конструкция, представляющая элементарную синтаксическую единицу

literal

: _литерал_

  Лексема, непосредственно представляющая некоторое значение

locus of control

: _локус контроля_

  Месторасположение управляющих команд; подпрограмма, сопрограмма или тред

log

: _журнал_; _протокол_

logging

: _журналирование_; _протоколирование_; _регистрация событий_

log message

: _регистрационная запись_

long-term

: _перспективный_

pattern

: _закономерность_

pragmatics

: _практика применения_

random

: произвольный

  _at random times — в произвольные моменты времени_

range

: _участок_

  _range within the program — участок программы_

reverse

: _оборотный_

  _reverse proxy-server — оборотный прокси-сервер_

runtime

: _рабочий модуль_

sandbox

: _изолированное окружение_

sanity check

: _санитарная проверка_; _проверка исправности_

sequence

: _ряд_

specifier

: _определитель_

statement

: _предложение_; _инструкция_; _оператор_; _выражение_

tool

: _инструментальная программа_

translation

: _трансляция_

  Преобразование программы, представленной на одном языке программирования, в
  программу на другом языке и в определенном смысле равносильную первой

type checker

: _контролёр типов_

value, data value

: _величина_; _экземпляр данных_; _значение_
