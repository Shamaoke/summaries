# Клавиатурные комбинации #
{: id="Клавиатурные_комбинации" }

`Alt+Y, Alt+Y`
`Alt+Y, V` (пользовательская настройка)

: Включить/отключить режим эмуляции редактора Vim (FakeVim)

`Ctrl+K`

: Перейти в режим обнаружения/поиска сущностей (Locator)

`Ctrl+Shift+U`

: Найти символ под курсором

`Alt+0`
`Alt+Y, L` (пользовательская настройка)

: Включить/отключить левую панель

`Shift+Alt+0`
`Alt+Y, R` (пользовательская настройка)

: Включить/отключить правую панель

`Alt+Y, F` (пользовательская настройка)

: Включить отображение файлов в левой панели

`Alt+Y, U` (пользовательская настройка)

: Включить отображение дерева сущностей в текущем файле (C++, QML)

`Alt+Y, M` (пользовательская настройка)

: Переключить отображение режимов редактора

`Alt+Y, K` (пользовательская настройка)

: Включить отображение закладок (в правой панели)

`Alt+Y, O` (пользовательская настройка)

: Включить отображение открытых файлов

# Фильтры режима обнаружения #
{: id="Фильтры_режима_обнаружения" }

Перечень фильтров обнаружения отображается во всплывающем окне при фокусировке
поля ввода режима обнаружения.

По умолчанию активны фильтры поиска по строке и колонке в текущем файле, —
`l␣<строка>:<колонка>`, перехода к открытому файлу текущего проекта, — `o␣`, и
открытие файла в любом открытом проекте, — `a␣`. Для использования этих фильтров
префиксы обнаружения вводить не требуется.

Для перемещения по списку результатов использовать комбинации `Ctrl+N`/`Ctrl+P`.

Для ограничения поиска использовать спецсимволы `*` — любое количество любых
символов и `?` — один любой символ.

Между именем фильтра и поисковым термом необходимо ставить пробел `␣`.

`.␣`

: Символы C++ в текущем открытом файле

`:␣`

: Символы C++ в файлах проекта

`a␣` (активен по умолчанию)

: Файлы в любом открытом проекте

`l␣<line>:<column>` (активен по умолчанию)

: Строка и колонка в текущем открытом файле

`m␣`

: Функции C++ и QML

`o␣` (активен по умолчанию)

: Файл в текущем открытом проекте
