`file -i|--mime note.txt`

: * Определить тип указанного файла

  * Вывести медиатип файла (mime-type)

  * Вывести кодировку файла

`install -m|--mode MODE /dev/null FILE`

: * Создать новый файл `FILE`

  * Установить указанные права доступа `MODE` для созданного файла (например, `755`)

`pstree -U -p`

: * Отобразить дерево процессов;

  * Использовать символы Юникода для отрисовки дерева (`-U`);

  * Отображать идентификаторы процессов — PID (`-p`).

`pstree -T`

: * Отобразить дерево процессов;

  * Скрывать треды. Отображать только процессы.

`pstree -t`

: * Отобразить дерево процессов;

  * Отображать имена для тредов.

`pstree -a`

: * Отобразить дерево процессов;

  * Отображать аргументы командной строки для процессов.

`zip -r|--recurse-paths ../zipped_dir.zip * -x|--exclude "./exclude/*"`

: * Создать zip-архив;

  * Включить в архив файлы в подкаталогах (`-r`);

  * Исключить из архива все файлы из указанного каталога (`-x`);

    _Ключ должен находиться после перечня файлов_.
