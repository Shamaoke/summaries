Перечень команд

Прочие

task color

Вывести используемую цветовую палитру в текущем эмуляторе терминала

Настройка

_forcecolor={on|off}

Активировать (on) или деактивировать (off) цветной вывод

include FILE

Импортировать внешний файл настроек или тем оформления (FILE)

verbose={PRESET|TOKEN_LIST}

Установить уровень детализации и информативности вывода

Определяет, какие служебные сообщения, предупреждения, заголовки и сноски утилита выводит вместе с выводом основных данных задач. Позволяет полностью отключить текстовый «спам» или, наоборот, включить подробные подсказки. Принимает готовые пресеты (PRESET) или список отдельных токенов через запятую (TOKEN_LIST).

Пресеты

nothing

Выводить только данные

default

Выводить стандартный набор данных

all

Выводить все данные

Токены

affected

Уведомлять о количестве измененных задач и типе изменения

new-id

Выводить идентификатор только что созданной задачи

label

Показывать заголовки столбцов таблиц

footnote

Выводить итоговые сноски под таблицами и графиками

override

Предупреждать о том, что заданные через конфигурационный файл настройки были изменены в текущей команде через аргумент командной строки

project

Предупреждать о том, что только что созданная задача была отнесена к новому ещё не созданному проекту

blank

Добавлять пустые строки-отступы до и после таблиц для улучшения читабельности

defaultwidth=NUMBER defaultheight=NUMBER

Установить количество символов по горизонтали (defaultwidth) и количество строк по вертикали (defaultheight) для вывода в конвейер или файл

Возможные значения

NUMBER > 0

Задать жесткий размер

NUMBER == 0

Отключить жесткий размер

Taskwarrior — консольный менеджер задач

💻 1. Основные команды

Вся работа строится по принципу: task <фильтр/ID> <команда> <модификаторы>.

Управление жизненным циклом (Модель: Резерв -> Текущие -> Архив)

  • task add <текст> — Добавить новую задачу (автоматически попадает в Резерв).
  • task <ID> start — Начать выполнение задачи (перенос в Текущие, добавляет тег +ACTIVE).
  • task <ID> done — Отметить задачу как выполненную (перенос в Архив, статус completed).
  • task <UUID> modify status:pending — Извлечь задачу из Архива обратно в Резерв.
  • task <ID> delete — Логически удалить задачу из списка (статус deleted).
  • task purge — Физически стереть все удаленные задачи из базы SQLite навсегда.
  • task undo — Отменить последнее совершенное действие.

Работа с тегами и аннотациями

  • task <ID> modify +тег1 +тег2 — Добавить сразу несколько тегов к задаче.
  • task <ID> modify -тег1 — Удалить тег с задачи.
  • task <ID> annotate "<текст>" — Добавить многострочное описание/заметку (в стиле тела коммита Git).
  • task <ID> edit — Открыть задачу в текстовом редакторе для детального изменения аннотаций.

📊 2. Команды вывода и визуализации

Для мониторинга в реальном времени команды запускаются внутри утилиты hwatch.

  • task list — Стандартная таблица всех активных задач.
  • task all — Вывод абсолютно всех задач (Pending, Completed, Deleted).
  • task completed — Вывод только выполненных задач (Архив).
  • task ready — Список задач, готовых к выполнению (без отложенных и заблокированных).
  • task active — Список задач, запущенных в данный момент (+ACTIVE).
  • task burndown — График сгорания задач по дням (.weekly — по неделям, .monthly — по месяцам).
  • task ghistory — Цветная гистограмма соотношения созданных и выполненных задач по месяцам.
  • task info <ID/UUID> — Полная системная информация о задаче (включая историю и аннотации).

⚙️ 3. Конфигурация (~/.config/task/taskrc)

Оптимизированные настройки для бесшовной интеграции с конвейерами (pipe), less и hwatch.

```text # Пути к базе данных (оптимизировано под бэкап и Unison) data.location=/mnt/data/local/task

Включение встроенной темной темы оформления

include /usr/share/doc/task/rc/dark-256.theme

Отключение ограничения ширины (каждая задача строго в одну строку для скроллинга в hwatch)

defaultwidth=0

Принудительный цвет при передаче в pipe/less

_forcecolor=on

Отключение детекции TTY терминала (предотвращает появление звездочек/крестиков в less)

detection=off

Отключение предупреждений о переопределении конфигурации в CLI (чистый вывод в tmux)

verbose=nothing ```

🚀 4. Примеры интеграции (tmux + hwatch)

Вывод цветного графика Burndown в панель tmux

Команда автоматически адаптирует сетку под геометрию панели без служебного спама: bash hwatch "task rc.defaultwidth:\$COLUMNS rc.defaultheight:((LINES + 2)) burndown"

Настройка панелей для трех категорий задач

```bash # Панель “Текущие” hwatch “task rc.verbose:label,footnote,affected +ACTIVE list”

Панель “Резерв”

hwatch “task rc.verbose:label,footnote,affected -ACTIVE list”

Панель “Архив”

hwatch “task rc.verbose:label,footnote,affected completed” ```
