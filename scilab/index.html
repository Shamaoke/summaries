Опции командной строки

-nw

Запустить приложение в консольном режиме с возможностью отображения информации в окнах

-nwni

Запустить приложение в упрощенном консольном режиме без возможности отображения информации в окнах

Команды

Основные

exit

Завершить текущую сессию

Консоль

clc

Очистить окно ввода-вывода

Поток управления

pause

Приостановить запущенную программу с предоставлением возможности ввода команд

resume

Продолжить выполнение приостановленной программы

Переменные

clear

Удалить указанные переменные

Функции

exec

Выполнить сценарий из файла
