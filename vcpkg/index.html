Команды

Режим манифеста

vcpkg new --application

Создать файл манифеста в текущем проекте.

Команда vcpkg new не может быть вызвана без опций командной строки. Существует два варианта: --application — для проектов, не предназначенных для распространения через систему vcpkg, и --name NAME --version VERSION — для проектов, предназначенных для распространения через систему vcpkg.

vcpkg new --name NAME --version VERSION

  • Создать файл манифеста в текущем проекте;

  • Внести имя NAME и VERSION в сгенерированный данной командой файл vcpkg.json.

Список пакетов

vcpkg list

Вывести перечень установленных пакетов.

Указанная команда выведет пакеты, установленные локально для текущего пользователя в так называемом классическом режиме (classic mode), то есть, с помощью непосредственного вызова команды vcpkg install PACKAGE.

Для корректной работы команды глобальная переменная VCPKG_ROOT должна содержать путь к каталогу установки системы vcpkg, например: VCPKG_ROOT=$HOME/.local/share/vcpkg.

vcpkg list --x-full-desc

  • Вывести перечень установленных пакетов;

  • Не обрезать длинные строки.

vcpkg list --x-install-root DIRECTORY

Вывести перечень установленных пакетов;

Указанная команда выведет пакеты, установленные для текущего проекта в так называетмом режиме манифеста (manifest mode), то есть, в режиме объявления и управления зависимостями для некоторого проекта.

Параметр DIRECTORY должен указывать на каталог vcpkg_installed, который будет создаваться системой vcpkg в проектах, управляемых системой сборки CMake.
